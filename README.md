## Запуск

Использована версия Python 3.14.5.

1. Скачайте файлы репозитория (файлы `winequality-red.csv` и `winequality-white.csv` должен находиться рядом с `ml2.ipynb`).
2. Установите библиотеки:
   ```
   python -m pip install -r requirements.txt
   ```
3. Запустите Jupyter:
    ```
    python -m jupyter notebook
    ```
4. Откройте ml2.ipynb и запустите все ячейки.
