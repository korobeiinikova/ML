## Запуск

Использована версия Python 3.14.5.

1. Скачайте файлы репозитория (файл `bodyfat.csv` должен находиться рядом с `ml_lab1.ipynb`).
2. Установите библиотеки:
   ```
   python -m pip install -r requirements.txt
   ```
3. Запустите Jupyter:
    ```
    python -m jupyter notebook
    ```
4. Откройте ml_lab1.ipynb и запустите все ячейки.
